# AZUR Art Credits

The menu art in this folder is original concept artwork generated for the AZUR browser battle royale project using the Tasklet image-generation capability and supplied visual references for broad style guidance. It depicts an original coastal island, airship, and six original expedition characters; it contains no logos, lettering, or copied game characters.

- `horizon-source.png`: original wide island key-art source.
- `horizon.webp` / `horizon.jpg`: optimized menu derivatives (1280×720).
- `skins-source.png`: original six-character contact-sheet source.
- `skins.webp`: optimized contact sheet.
- `char-*.webp`: equal 418×627 crops from the contact sheet.

These images are menu concept art only. The game uses separate procedural 3D models and UI rendering; those in-game models are not intended to be identical to these renders.
